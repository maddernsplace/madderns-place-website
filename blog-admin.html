GitHub Publishing
How to create a token:
  1. Go to github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens
  2. Click Generate new token
  3. Set Repository access to your site repo
  4. Under Permissions → Repository → Contents, choose Read and write
  5. Copy the token (starts with github_pat_) and paste it below

Tokens expire — if publishing was working before, generate a new one and paste it here.
e.g. maddernsplace/madderns-place-website
